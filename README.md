# Vimarsh Jaiswal — React Portfolio

## Preview in StackBlitz (no Node.js required)

1. Open https://stackblitz.com/
2. Choose **Create New → Import Project**.
3. Upload this ZIP file.
4. StackBlitz installs dependencies and starts the Vite preview automatically.
5. Open the Preview panel.
